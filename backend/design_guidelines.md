# SonicIPChain - Audio Tokenization dApp Design Guidelines

## Design Approach
**Reference-Based Approach**: Drawing inspiration from Spotify's audio interface patterns, Opensea's NFT marketplace aesthetics, and Linear's modern dashboard design to create a cutting-edge audio tokenization platform.

## Core Design Principles
- **Audio-First Visual Language**: Every design element should reflect the audio nature of the platform
- **Trust & Security**: Visual indicators that communicate blockchain security and privacy
- **Creator Empowerment**: Interface that makes complex tokenization feel intuitive
- **Dual-Portal Clarity**: Clear distinction between Seller and Consumer experiences

## Color Palette

### Primary Colors
- **Deep Purple**: 260 85% 15% (primary brand, headers, CTAs)
- **Electric Blue**: 220 90% 50% (accent, interactive elements)
- **Midnight Black**: 240 10% 8% (backgrounds, depth)

### Supporting Colors
- **Soft White**: 0 0% 98% (text, cards in light mode)
- **Warm Gray**: 220 8% 25% (secondary text, borders)
- **Success Green**: 142 76% 36% (verification, upload success)
- **Warning Amber**: 43 96% 56% (encryption status, pending states)

### Gradients
- **Hero Gradient**: Deep purple to electric blue for main banners
- **Card Overlays**: Subtle purple to transparent for glassmorphism effects
- **Waveform Visualization**: Dynamic blue to purple gradients following audio intensity

## Typography
- **Primary**: Inter (modern, readable for UI text)
- **Display**: Space Grotesk (bold headers, brand elements)
- **Mono**: JetBrains Mono (wallet addresses, transaction hashes)

## Layout System
**Tailwind Spacing Units**: Consistently use 2, 4, 6, 8, 12, 16, 24 for all spacing to maintain visual rhythm.

## Component Library

### Navigation
- **Dual-Portal Switcher**: Toggle between IP Seller and Consumer modes
- **Wallet Connection**: Prominent Flow blockchain connection status
- **Identity Verification Badge**: Self Protocol verification indicator

### Audio Components
- **Waveform Visualizer**: Interactive audio preview with playback controls
- **Upload Zone**: Drag-and-drop with live encryption status
- **Audio Player Card**: Compact player with demographic tags

### Tokenization Interface
- **Minting Progress**: Step-by-step visual flow with blockchain confirmations
- **Attribute Selector**: Visual tag system for demographics (age, gender, language, accent)
- **Pricing Configuration**: Intuitive tier selection with usage rights

### Marketplace Features
- **Filter Sidebar**: Advanced demographic and audio type filtering
- **Audio Grid**: Cards showing waveform previews and metadata
- **Licensing Modal**: Clear usage rights and pricing breakdown

### Data Visualization
- **Analytics Dashboard**: Creator earnings and usage statistics
- **Transaction History**: Blockchain transaction timeline
- **IPFS Status**: Encrypted storage indicators

## Key UX Patterns

### IP Seller Portal
1. **Onboarding Flow**: Self Protocol verification → Audio upload → Attribute setting → Tokenization
2. **Dashboard**: Upload progress, minted tokens, earnings overview
3. **Audio Management**: Library of uploaded/tokenized audio with editing capabilities

### IP Consumer Portal
1. **Discovery**: Browse/search audio by demographics and type
2. **Preview System**: Instant audio preview with licensing options
3. **Purchase Flow**: License selection → Wallet confirmation → Asset delivery

## Visual Treatments

### Glassmorphism Cards
- Semi-transparent backgrounds with subtle blur effects
- Soft shadows and gentle borders
- Perfect for overlaying on gradient backgrounds

### Audio Visualization
- Real-time waveform rendering during upload/playback
- Animated progress indicators for encoding/encryption
- Dynamic color mapping based on audio intensity

### Blockchain Integration
- Transaction status animations
- Flow blockchain branding integration
- Visual confirmations for minting/licensing

## Images
- **Hero Section**: Large waveform visualization background (full viewport height)
- **Feature Cards**: Abstract audio wave illustrations
- **User Avatars**: Generated geometric patterns for privacy
- **No photography**: Keep focus on audio and interface elements

## Accessibility
- High contrast ratios for all text combinations
- Keyboard navigation for all audio controls
- Screen reader descriptions for waveform visualizations
- Dark mode optimized throughout

This design system creates a professional, audio-centric interface that clearly communicates the platform's blockchain capabilities while maintaining an intuitive user experience for both creators and consumers.
